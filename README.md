# PascalBook: Интерактивный учебник по Pascal ABC

Образовательный веб-ресурс, созданный в 2021 году для структурирования учебного материала по языку программирования Pascal ABC.

## 🌐 Живая демонстрация
Вы можете посмотреть работающую версию учебника здесь: 
👉 **[Открыть PascalBook](https://timatti.github.io/pascalbook/html/)**

## 📖 О проекте
Проект представляет собой статический сайт, содержащий систематизированный материал от базового синтаксиса до работы с графикой и ООП. Он был создан как альтернатива разрозненным школьным конспектам.

## 🛠️ Технологии
* HTML5
* CSS3
* **Bootstrap** (для адаптивной верстки и использования готовых UI-компонентов)
* JavaScript (для навигации и интерактивных элементов)
* GitHub Pages (для хостинга)

## 🚀 Как запустить локально
Проект не требует установки зависимостей или сборки. Просто клонируйте репозиторий и откройте файл `index.html` в любом браузере.
